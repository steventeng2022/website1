# Steven — Personal Introduction

A responsive static personal website built with HTML, CSS, and JavaScript.

## Edit before publishing

Open `index.html` and replace `hello@example.com` with your real email address.

## GitHub upload

Copy all files from this folder into your cloned `website1` repository, then run:

```powershell
git add .
git commit -m "Add personal introduction website"
git branch -M main
git push -u origin main
```

## Cloudflare Pages

Connect the GitHub repository in Cloudflare Pages. Use no framework preset, leave the build command blank, and set the output directory to `/`.
